# GO TRADE — Intelligent Trading System v9.1

Platform AI Trading lengkap: **live chart real-time (Binance)**, AI signals, auto-trading, wallet, referral, Admin Center, **login real (Supabase)**, dan notifikasi.

UI diperbarui agar sangat mewah & profesional, matching layout screenshot (light workspace, signal cards, network & referral, deposit dengan QR, dashboard ringkasan akun).

## Fitur
- Login / Register (Supabase Auth + local fallback) — form mewah split-screen
- Session persistence
- Dashboard ringkasan akun, performa portofolio, paket auto-trading
- Signals card style (BTC/USDT Buy, ETH/USDT Sell, dll)
- Live Charts per pair (Lightweight Charts + data Binance)
- Network & Referral (kode, stats, empty state)
- Deposit (QR + form + bank optional)
- Withdrawal, Bonus Tracking, Trade History, Notifications
- Admin Center lengkap
- Dark / Light mode
